# 🐐 GoatLessPaper

A lightweight goat herd register for smartphones and desktop browsers.

## Features

- Editable herd table and individual animal records
- Full-screen Data Matrix scanner for Tip Tag labels and electronic identifiers
- Format example: `50 FR 35 576` → Tip Tag `50`, farm EDE `576`
- Herd dashboard, search, local backups, and Excel-compatible CSV import/export
- iOS-style bottom navigation and camera zoom controls where supported

## Publish on GitHub Pages

Go to **Settings → Pages → Deploy from a branch → main / (root)**.

**Data protection:** Records are stored locally in the browser and are not synchronized across devices. Back up your data regularly before clearing browser storage or switching devices.
